# Anna Bot

Telegram bot designed to help users track and manage their personal finances.

## Tech Stack

- Python 3.14
- SQLAlchemy
- PostgreSQL (Supabase)
- python-telegram-bot

## Setup

1. Clone the repository
2. Install dependencies with `poetry install`
3. Create a `.env` file based on `.env.example` (not yet implemented)
4. Run with `poetry run python src/anna/main.py`
